# Shell Scripting Industry-Level Projects 🚀

This repository contains real-world **shell scripting projects** designed for automation, system administration, and DevOps.  

## 📌 Projects
1. **Database Backup Script** – Automates MySQL backups weekly using cron.
2. **Upgrade Database Script** - Autmates Database Upgrade weekly using cron. 
. **Log Rotation** – Rotates and compresses logs to save disk space.  
. **User Management** – Bulk user creation/deletion from CSV.  
. **System Monitoring** – Tracks CPU, memory, and disk usage.  

## 🎯 Purpose
This repo serves as a **portfolio** to showcase shell scripting skills relevant for IT, DevOps, and System Admin roles.
