# 09-db-process-check

## Usage
This script connects to the MySQL database and lists all running processes.

### Steps:
1. Update DB credentials inside the .env file
   ```bash
   DB_HOST="localhost"
   DB_USER="root"
   DB_PASS="your_password"

2. Run the script:
   ./db_process_check.sh

3. Check logs:
   db_process_check.log
